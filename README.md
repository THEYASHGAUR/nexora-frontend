# Nexora — Frontend

The modern web client for **Nexora** — an AI-powered voice mock interviewer and resume analyzer.

## 🚀 Tech Stack

- **Framework**: Next.js 15 (App Router, React 19)
- **Styling**: Tailwind CSS v4, OKLCH design system
- **Animations & Icons**: Motion, Lucide React
- **Charts**: Recharts

## 📁 Key Routes

- `/landing` — Product Landing Page
- `/login` — User Authentication (Login & Signup)
- `/` — Resume & JD Match Analyzer
- `/ai-mock-interview` — Live Voice AI Mock Interview
- `/interview-questions` — Technical Interview Insights
- `/hr-dashboard` — Candidate Analytics Dashboard

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
npm start
```
